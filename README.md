# Aurora Commerce — Advanced Shopify Portfolio Theme

A custom Shopify Online Store 2.0 portfolio project built to demonstrate practical theme-development skills.

## Features

- Shopify Liquid storefront architecture
- JSON templates
- Reusable sections and blocks
- Section groups for announcement/header/footer
- Responsive navigation
- Product gallery and variant selection
- Product metafield fallback for short description
- Merchant-editable product accordions
- Collection sorting
- Product recommendations
- Cart quantity updates and checkout
- Store search
- Newsletter form
- Responsive images
- Accessibility-friendly labels and skip link
- Mobile-first responsive behavior

## Before putting this project on your CV

1. Upload and test it in a Shopify development store.
2. Add products, collections, menus, and images through Shopify Admin.
3. Test product variants, cart, search, sorting, and recommendations.
4. Add screenshots to your GitHub repository.
5. Record a short walkthrough of the Theme Editor.
6. Be ready to explain the Liquid objects and section schemas you used.

Only claim features that you personally tested and understand.
